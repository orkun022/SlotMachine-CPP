# Slot Machine Game (C++)

A simple terminal-based slot machine game written in C++.  
Each spin randomly displays 3 symbols. If all 3 match, the player wins.

## Features
- Console-based interface
- Symbol display with emojis
- Random spin logic
- Play-again loop

## How to Run
Compile with g++ or any C++ compiler:

```bash
g++ main.cpp -o slot
./slot
